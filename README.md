# 清翼居府中館 飯店排班系統

目前版本：1.2.3（2026-10-29 正式版）

## 系統需求
- Windows 10/11（64 位元，不需安裝任何其他軟體，打包版）
- 或 Docker（`ghcr.io/shcjosh/hotel-scheduler:<版本>`，Unraid/Tower 部署用）

## 使用方式（打包版）
- Windows：解壓縮 `hotel-scheduler-*-windows-x64.zip`，雙擊 `hotel-scheduler.exe`
- 啟動後瀏覽器自動開啟 http://localhost:8765
- 關閉瀏覽器分頁或點右上角「關閉系統」按鈕，程式即自動結束

資料庫 `data/scheduler.db` 與執行檔同層，整個資料夾可複製到其他機器直接使用。

## 功能
- A/B/C/D/M 班排班（CP-SAT 求解引擎，13 條硬性 + 9 條軟性約束 + 店長卡班上限，含跨月連休公平自動加權）
- 白天班組合規則：週五/六 4 人排 2A2C、3 人排 ABC；平日 3 人排 ABC、避免 4 人
- 員工管理（日班櫃台/大夜/C+D備援/管理職/房務，含暱稱、自訂排序、標籤 TAG）
- 離職員工處理：設「離職日（最後上班日）」保留歷史班表（名字反灰 + 離職徽章，離職月後消失）；月中離職自動停止排班；「刪除」僅限無歷史資料者
- 二館支援（員工標籤）：完全手動排 A1/C1/D1、豁免個人規則、計入每日覆蓋
- 支援請求一天最多一個（H14）：外部人力優先上 A（偏好 A 班），缺得較多的 C 班由店長等內部人力補；自動偵測與手動新增皆遵守，同日已有請求會被擋下
- 休假管理（指定休假 + 特休/事假/病假/颱風假等自訂假別 + 連休計數；圓形 Icon 選人、常用假別單鍵選取）；大夜假別可直接在排班表格位設定，休假管理新增/移除也會同步大夜格位
- 特休紀錄（週年制）：設定到職日自動依勞基法計算各週年期間額度（滿 6 個月 3 天、滿 1 年 7 天…滿 10 年起每年 +1、上限 30 天）；班表上整天特休顯示「特 1、特 2…」累計編號；可補登期初已用天數與個別覆寫額度；半天特休以手動紀錄處理（不涉排班）；休假管理頁與統計頁顯示各期間額度/已用/剩餘（超用僅提示不阻擋）；房務的系統外特休在房務班表頁的「特休紀錄」面板維護
- 跨月銜接設定與預覽
- 大夜班次於排班表直接輸入（畫筆/格位微調排 D、休或假別，含颱風假等自訂假別）+ D 班備援指示 + 逐人規則開關（員工表單內設定，含無視所有規則）
- 一鍵排班（整合於休假管理頁）+ 失敗診斷 + 自動支援偵測（排不出時建議缺班日/班）
- 店長卡班上限：休假管理頁「開始排班」旁可設「店長最多卡班 __ 天（A/C）」（每月一個值、每位管理職各自計算）；超過上限的缺口自動轉為支援請求
- 排班表手動調整（頂部快捷畫筆連選多格 + 批次檢查與強制套用）
- 排班表「覆蓋」列圖示化：綠圈＝A/C 覆蓋、綠同心圓＝A/B/C 覆蓋、紅字＝缺班（不含 D；A1/C1 計入）
- 班表狀態管理（草稿/發布/鎖定）+ 版本快照還原 + 調班紀錄
- 整月規則驗證報告（H1~H13 + S1~S10）
- 統計報表 + CSV/JSON 匯出
- 整庫備份與匯入（統計報表頁「資料庫備份」區）：一鍵下載整庫 SQLite（含全部月份、
  設定、快照、調班紀錄），拿到另一台機器（含 Docker 版）覆蓋匯入；匯入前驗檔
  （非 SQLite／缺表／毀損一律拒絕）並自動備份舊庫（留最近 5 份）。整庫覆蓋、
  非合併，兩邊各改各的會以匯入方為準
- 班表列印預覽／PDF（橫式 A4，貼近櫃台 xlsx）：
  - 休假格依「每週第一休＝斜線／、第二休＝交叉 X」自動畫線，跨月一起判斷
    （上月無班表時會用跨月設定的上月末休假補足，例如 9/2 依 8/31 判為 X）
  - 主管班（M／空白）預設留白，頁尾註明「空白＝M 主管班 09:00-17:00」；可切換顯示 M
  - 兩列日期／星期、粗週框線、左側單位／類別／姓名欄、櫃台＋房務同一張表
  - 可設定每月節日／備註（元旦、尾牙、主會…，連續文字自動合併）、頁尾注意事項、分館名稱
  - 底部上班時段、假別圖例、製表人／單位主管／會計簽名欄、「新訂加續住」手寫列
  - 即時預覽後再列印／存 PDF；可選整週模式、顯示房務、週末淺灰底
- 房務班表頁：房務人員純手動用畫筆排班（A 09:00-18:00／假別／休），與櫃台互不干涉、不做規則檢測；下方可選人維護該房務的特休紀錄（系統外特休）
- 清空班表安全化：鎖定月份一律要先解鎖才能清空；清空時連同該月支援請求全清、月狀態回草稿（櫃台指定休假/請假紀錄保留；清空大夜班表會一併清除大夜假別）
- 可修改抬頭（飯店名稱）
- 瀏覽器關閉自動偵測（關分頁即結束程式）+ 一鍵關閉系統按鈕

## 開發環境
- Backend: Python 3.11+ / FastAPI / OR-Tools / SQLite
- Frontend: React 19 / TypeScript / Tailwind CSS / Vite

## 開發啟動
```bash
# 後端
cd backend && .venv/bin/python -m uvicorn app.api:app --port 8765

# 前端（開發模式，proxy /api → 後端）
cd frontend && npm run dev

# 或單一後端模式（服務前端 build）
cd frontend && npm run build
cd backend && .venv/bin/python run.py
```

## 產生測試資料
```bash
cd backend && .venv/bin/python tests/seed_dev.py
```

## 打包部署
```bash
cd frontend && npm run build
cd ../backend && .venv/bin/python build_spec.py
# 產出：backend/dist/hotel-scheduler/（onedir）
#       backend/dist/hotel-scheduler-{version}-{platform}-{arch}.zip / .tar.gz
```
注意：PyInstaller 不支援跨平台，需在目標平台執行（Windows 產出 .exe + .zip，
Linux 產出 ELF + .tar.gz）。版本號統一在 `backend/app/version.py`。
